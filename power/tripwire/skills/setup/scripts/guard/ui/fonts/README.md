# ui/fonts

무대 화면이 `@font-face`로 읽는 글꼴. 배포본을 고치지 않고 파일 이름만 바꿨다.

| 파일 | 글꼴 | 판 | 받은 곳 | 라이선스 |
|---|---|---|---|---|
| `PretendardVariable.woff2` | Pretendard Variable(굵기 45~920) | 1.3.9 | github.com/orioncactus/pretendard 태그 `v1.3.9`의 `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2` | SIL OFL 1.1 — `LICENSE-Pretendard.txt` |
| `IBMPlexMono-400.woff2` | IBM Plex Mono Regular | 2.5.0 | npm `@ibm/plex-mono@2.5.0`의 `fonts/complete/woff2/IBMPlexMono-Regular.woff2` | SIL OFL 1.1 — `LICENSE-IBMPlexMono.txt` |
| `IBMPlexMono-500.woff2` | IBM Plex Mono Medium | 2.5.0 | 같은 곳의 `IBMPlexMono-Medium.woff2` | 같음 |
| `IBMPlexMono-600.woff2` | IBM Plex Mono SemiBold | 2.5.0 | 같은 곳의 `IBMPlexMono-SemiBold.woff2` | 같음 |
| `PermanentMarker.woff2` | Permanent Marker(라틴) | Google Fonts | `https://fonts.gstatic.com/s/permanentmarker/v16/Fh4uPib9Iyv2ucM6pGQMWimMp004La2Cfw.woff2` | Apache 2.0 — `LICENSE-PermanentMarker.txt`(github.com/google/fonts `apache/permanentmarker/LICENSE.txt`) |
| `Anybody.woff2` | Anybody(라틴, 굵기 100~900·너비 50~150%) | Google Fonts | `https://fonts.gstatic.com/s/anybody/v13/VuJxdNvK2Ib2ppdWSKHdOQ.woff2` | SIL OFL 1.1 — `LICENSE-Anybody.txt`(github.com/google/fonts `ofl/anybody/OFL.txt`) |
